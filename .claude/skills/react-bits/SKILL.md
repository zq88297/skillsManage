# React Bits — Design System → Component Matching

Bridge between UI design systems and the React Bits component library. Maps 49 design styles (from ui-ux-pro-max, frontend-design, design-taste-frontend) to 135 animated React components with install commands and design token integration.

## When to Apply

### Must Use

This skill must be invoked when:

- User asks "推荐 React Bits 组件" / "what React Bits components go with [style]"
- User wants to install matching animated components after generating a design system
- User has a MASTER.md (from ui-ux-pro-max --persist) and wants component recommendations
- User says "匹配组件" / "match components" / "选组件" in context of a design style

### Recommended

- After ui-ux-pro-max, frontend-design, or design-taste-frontend finishes generating a design
- User has chosen a visual style but doesn't know which component library to use
- User wants pre-configured component props matching their design tokens

### Skip

- Pure backend/API work
- Projects not using React
- User hasn't chosen or doesn't need a visual design style

## How to Use

### Step 1: Identify the Design Style

Get the style name from one of these sources:

| Source | How to Get It |
|--------|---------------|
| **ui-ux-pro-max output** | The `--design-system` output shows the style name (e.g., "Glassmorphism") |
| **MASTER.md file** | Generated by `--persist`, contains full design tokens |
| **User explicitly names it** | e.g., "I want brutalism style components" |
| **frontend-design output** | Look for the committed aesthetic direction |

### Step 2: Run the Matching Engine

```bash
# Match by style name (fastest)
python skills/react-bits/scripts/match.py --style "glassmorphism"

# Match from MASTER.md (extracts style + motion level automatically)
python skills/react-bits/scripts/match.py --design-system design-system/my-project/MASTER.md

# Match by style + filter by category
python skills/react-bits/scripts/match.py --style "brutalism" --category text

# Match by style + target motion level (1-10)
python skills/react-bits/scripts/match.py --style "cyberpunk" --motion 8

# Get JSON output for programmatic use
python skills/react-bits/scripts/match.py --style "glassmorphism" --format json

# List all available styles
python skills/react-bits/scripts/match.py --list-styles

# Show all components in a category
python skills/react-bits/scripts/match.py --all --category background
```

### Step 3: Review Recommendations

The output organizes components by category with priority tiers:

- **⭐ 首选 (Primary)**: Top 4-6 strongly recommended components — use these first
- **备选 (Secondary)**: 4-8 additional good matches — use for more variety
- Each component shows: motion level, description, and ready-to-run install command

### Step 4: Install and Integrate

Install recommended components:

```bash
npx shadcn@latest add @react-bits/<ComponentName>-TS-TW
```

Wire design tokens to component props:

```tsx
<ComponentName
  style={{
    '--color-primary': 'var(--color-primary)',
    '--color-background': 'var(--color-background)',
    borderRadius: 'var(--radius-lg)',
  }}
/>
```

## Integration with Other Skills

react-bits is designed to work as a **bridge** in the design-to-code pipeline. Here's how it connects with each skill:

### ← ui-ux-pro-max (Design System Generator)

**Trigger**: After `--design-system` or `--persist` generates design output.

```bash
# Direct style matching from design system output
python skills/react-bits/scripts/match.py --style "Glassmorphism"

# Read from persisted MASTER.md
python skills/react-bits/scripts/match.py --design-system design-system/my-project/MASTER.md

# Persist to session context
python skills/react-bits/scripts/match.py --style "Glassmorphism" --context-dir .claude/context
```

react-bits extracts the style name and motion dial from MASTER.md, maps them to components, and writes `components.md` to the context directory.

### ← frontend-design / design-taste-frontend (Aesthetic Code Generators)

**Trigger**: After an aesthetic direction is chosen (e.g., "luxury-refined", "brutalist-raw").

```bash
# Map frontend-design's aesthetic direction to components
python skills/react-bits/scripts/match.py --style "frontend-design:luxury-refined"
```

Matches the 11 extreme aesthetic directions from frontend-design to React Bits components.

### ↔ project-workflow (Project Orchestrator)

**Phase ② (方案设计)**: After UI generation, react-bits is invoked to recommend matching components. Results persist to `.claude/context/components.md`.

**Phase ③ (代码实现)**: At start of implementation, reads `components.md` and offers to install recommended components via `npx shadcn@latest add`.

```bash
# Auto-detect from project-workflow's design.md
python skills/react-bits/scripts/match.py --context-dir .claude/context
```

### → session-context (Cross-Session Persistence)

When used with `--output-file .claude/context/components.md`, react-bits writes a structured component recommendation report. The next session loaded by session-context picks up:
- Component inventory in `.claude/context/components.md`
- Key files via `## 📂 关键文件清单` in `current-task.md`

### → impeccable (UI Optimization)

After react-bits recommends components and they're installed, impeccable can polish their usage with UX review, accessibility checks, and motion refinement.

### Integration Flow Summary

```
ui-ux-pro-max / frontend-design
  │  生成设计系统
  │
  ├─→ react-bits 匹配组件
  │     │  读取 MASTER.md 或 style name
  │     │  映射 49 风格 → 135 组件
  │     │  输出推荐 + install 命令
  │     │  写入 .claude/context/components.md
  │     │
  │     └─→ 安装组件 (npx shadcn@latest add)
  │           │
  │           └─→ impeccable 优化 + 抛光
  │
  └─→ session-context 持久化
        下一会话自动加载
```

## Tips for Better Results

| Situation | What to Do |
|-----------|------------|
| Too many components suggested | Use `--category` filter to focus on one category at a time |
| Style not found exactly | Try partial name: "glass" instead of "Glassmorphism & Swiss" |
| Need more animation intensity | Use `--motion 8` to filter for high-motion components |
| Need fewer animations | Use `--motion 2` to filter for subtle/subdued components |
| Want all components in a category | Use `--all --category background` |
| MASTER.md parsing fails | Fall back to `--style "Style Name"` with explicit name |
| Unsure which style to use | Run `--list-styles` to browse all 49 options |

### Pre-Delivery Checklist

- [ ] Match engine returns relevant components for the target style
- [ ] Install commands are copy-paste ready
- [ ] Component props reference design system CSS variables (not hardcoded values)
- [ ] Motion level of selected components aligns with the design system's motion dial
- [ ] Component dependencies (motion, gsap, three) are compatible with the project stack
- [ ] Both primary and secondary recommendations reviewed before installing
