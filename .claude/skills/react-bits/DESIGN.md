# DESIGN.md — react-bits Skill

## Rationale

### Problem
After design skills (ui-ux-pro-max, frontend-design, design-taste-frontend) generate a design system with style, colors, typography, and motion specifications, the user faces a gap: **which components should they use to implement this design?** The React Bits library has 135 components across 4 categories, but there's no automated way to map "Glassmorphism" → "GlassSurface, FluidGlass, Aurora..."

### Solution
A skill that reads design system output and maps it to matching React Bits components. The matching is powered by a curated CSV mapping (49 styles × 135 components) with human-expert primary/secondary recommendations, plus a keyword-based fallback for unmatched styles.

### Why React Bits?

- **135 animated components** — largest open-source collection
- **shadcn CLI install** — copy-paste, not npm black-box
- **Design-aligned** — each component has a distinct visual style (glass, minimal, brutalism, cyberpunk, etc.)
- **Active development** — weekly updates, 43k+ GitHub stars
- **Free for commercial use** — MIT + Commons Clause

### Design Decisions

| Decision | Why |
|----------|-----|
| CSV for data, not JSON | Follows ui-ux-pro-max pattern; easy to edit in spreadsheets; git-friendly diffs |
| Two-tier recommendations (Primary/Secondary) | Prevents overwhelm (20+ recommendations) while still providing options |
| MASTER.md parsing | Enables seamless integration with ui-ux-pro-max --persist workflow |
| Keyword fallback | Covers future styles without requiring immediate CSV updates |
| Motion level filtering | Aligns with ui-ux-pro-max's --motion dial (1-10) |
| 4 output formats (markdown/json/text/table) | Covers terminal display, programmatic use, and documentation |

### Integration Points

- **ui-ux-pro-max**: Reads MASTER.md generated by `--persist` flag
- **frontend-design**: Style names from its 11 extreme aesthetic directions mapped in style_mappings.csv
- **design-taste-frontend**: Style keywords extracted from its design direction output
- **project-workflow**: Can be inserted as a step after the design phase

### Data Maintenance

When React Bits adds new components:
1. Add a row to `data/components.csv` with metadata
2. Add the component name to relevant styles in `data/style_mappings.csv`
3. The matching engine automatically picks up new entries
