# 启动项目工作流

为新项目、新功能或实现请求启动或恢复项目生命周期流程。

## 步骤

1. 检测上下文目录：
   - 默认使用 `.codex/context/`。
   - 如果 `.claude/context/` 已存在，则沿用它。

2. 创建或更新 `workflow-state.md`：

   ```markdown
   # 项目工作流状态
   - 项目: {项目名}
   - 阶段: 需求分析
   - 状态: 进行中
   - 开始时间: {datetime}
   - 最后更新: {datetime}
   - 下一步: 澄清需求
   ```

3. 判断是否需要完整流程：
   - 完整流程：宽泛项目、新功能、需求不清、架构变更、UI/产品工作、数据契约或高风险行为。
   - 快速通道：小范围修复、局部编辑、清晰实现请求，或已有需求/设计文档。

4. 完整流程下收集需求：
   - 阅读用户引用的文档、工单、截图、规格说明和现有代码。
   - 只问高价值问题。
   - 明确非目标、兼容范围、数据范围和外部依赖边界。
   - 捕获可验证的验收标准，包含输入/输出、可观察结果、边界场景和失败条件。
   - 当工作跨越当前对话时，写入 `requirements.md`。

5. 只有当验收标准足够清晰、可验证时，才进入方案设计。

## 输出

告诉用户当前阶段、未决问题和下一步具体动作。
